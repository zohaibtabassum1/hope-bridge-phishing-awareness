# Hope Bridge Foundation – Phishing Awareness Programme

## About the Project

The **Phishing Awareness Programme** is a cybersecurity awareness initiative created for Hope Bridge Foundation.

Its purpose is to educate people about phishing attacks, help them recognise suspicious emails, messages and websites, and encourage safer online behaviour.

## Live Website

Visit the published website:

[Phishing Awareness Programme](https://zohaibtabassum1.github.io/hope-bridge-phishing-awareness/)

## Project Features

- Custom SVG logo for Hope Bridge Foundation.
- Responsive landing page.
- Introduction to the phishing awareness programme.
- Phishing awareness article explaining common attacks and warning signs.
- Interactive three-question quiz with score calculation.
- Correct and incorrect answer feedback using JavaScript.
- Simulated phishing email exercise for educational purposes.
- Suspicious email reporting form.
- Formspree integration for receiving phishing reports.
- JavaScript form submission using Fetch API.
- Success and error messages after form submission.
- Responsive design for desktop and mobile devices.
- Navigation between website pages.
- Published using GitHub Pages.

## Simulated Phishing Exercise

The simulated phishing page provides a fictional suspicious email for educational purposes.

Users can examine the email, identify potential phishing indicators and submit a report through the reporting form.

The reporting form uses Formspree to process submissions without requiring a custom backend server.

## Purpose

This project is part of a cybersecurity awareness initiative focused on helping people identify phishing attempts and protect their personal information online.

## Limitations

- The quiz uses client-side JavaScript to check answers, which means the correct answers can be viewed through browser Developer Tools. This is acceptable for this project because the quiz is designed for phishing awareness and learning, not for a secure examination.
- The reporting form relies on Formspree, an external third-party service, to process submissions.
- GitHub Pages provides static website hosting and does not provide a custom server-side backend for this project.

A real assessment requiring answer confidentiality or sensitive information processing should use a secure backend with appropriate validation and security controls.
